## 📁 Стандарт структуры каждой папки
Каждая персональная папка девушки содержит единую архитектуру файлов:
```
01_Aimi_Sato/
├── profile_card.md         # Полная карта инфлюенсера: био, параметры, ДНК внешности, ЦА, гардероб, аккаунт
├── photos/                 # Фотоархив
│   ├── master/             # Мастер-фото и референсы лица/тела (для IP-Adapter, LoRA, Seed)
│   └── generated/          # Готовые генерации, фотосессии, трендовые сторис и посты
├── prompts/                # Промпты
│   ├── master_prompt.md    # Базовые мастер-промпты (Flux / Midjourney / SDXL), отрицательные промпты
│   └── dance_prompts.md    # Шаблоны промптов под динамичные танцевальные позы и тренды
└── video/                  # Сгенерированные видеоролики, анимации и танцевальные исходники
```

## 🚀 Регламент работы с проектом
1. **Идентификация:** Выберите девушку из каталога и перейдите в её папку.
2. **Мастер-профиль:** Изучите `profile_card.md` для понимания характера, мимики, динамики и стиля.
3. **Генерация фото:** Используйте `prompts/master_prompt.md` для получения эталонного лица.
4. **Генерация движений:** Применяйте динамические связки из `prompts/dance_prompts.md`.
5. **Хранение:** Все эталонные референсы лица сохраняются в `photos/master/`, а результаты — в `photos/generated/` и `video/`.
